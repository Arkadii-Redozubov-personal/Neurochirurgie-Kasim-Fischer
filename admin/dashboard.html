Automatische 1-Klick-Veröffentlichung aktiv

Mit einem Klick auf "Auf Website veröffentlichen" werden alle in dieser Admin-Konsole vorgenommenen Änderungen im Hintergrund auf den Server von my-bandscheibe.de übertragen. Die Website wird automatisch innerhalb von 1–2 Minuten aktualisiert.

Aktuelle Website-Inhalte in Firebase einlesen (Initialer Import / Reset)

Lädt alle echten, aktuellen Texte, Ärzte, Schwerpunkte, Behandlungen, Diagnostik, FAQ, Rezensionen und Standorte der Website in allen 5 Sprachen direkt in die Firebase-Datenbank ein.
