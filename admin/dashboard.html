Website synchronisieren
Exportiert alle Daten aus Firebase als JSON-Datei für den Python-Generator

Wie funktioniert die Synchronisierung?

  1. Klicken Sie auf "Daten exportieren" — eine Datei cms_data.json wird heruntergeladen.
  2. Legen Sie die Datei in den Hauptordner vertex/ Ihrer Website.
  3. Führen Sie den Python-Skript aus: python sync_cms.py
  4. Der Skript aktualisiert alle 30 HTML-Dateien automatisch!
